# homeIoT

## 概要

このリポジトリは、sierraが書いた同人誌「お天気ダッシュボードを作る」で使用したプログラムを格納しています。

## フォルダ構成

<pre>
.
├── log：ログファイルの格納場所。
├── package：自作のパッケージを格納しています。
├── streamlit：Streamlitの実行ファイル。
└──xml：動作確認用のxml。
</pre>

## 取得コード

- [main.py] 取得コード本体。
- [jma_xml.py] Atomフィードを取得して更新日を確認します。
- [yohou.py] 府県天気予報（R1）を取得します。
- [gaikyo.py] 府県天気概況を取得します。
